03 / Optional prerequisites, gear & Slayer readiness Expand to personalize

Set each requirement to Ready, Not ready, or Not sure. The JSON does not include this information. A “Not ready” requirement excludes affected tasks. “Not sure” applies a cautious ranking penalty unless you turn on strict filtering. Some requirements may be missing from this first metadata release. Recommended (rather than required) gear affects time estimates without blocking tasks.

Estimates are starting assumptions, not factual kill times. Edit any task's minutes under Why / effort to personalize the algorithm. It will recalculate the route immediately.

CA ROUTE v2 · Independent fan-made project; not affiliated with Jagex or RuneLite. Player data is handled by this browser using localStorage; clearing storage removes it. No analytics, external scripts, or upload endpoints. Wiki links open only if clicked.

Routing is a transparent greedy heuristic, not a globally optimal solver. Current built-in catalog: 655 tasks / November 2026. The imported JSON defines completion; an unlisted task is not assumed incomplete. Standard thresholds are used for Group Ironmen. OSRS Wiki · Exporter plugin
